## 一、AC 是什么？

**AC = Agent Core = 你的个人 AI 专家团。**

一套纯 Markdown 文件组成的角色系统。复制到任何地方，粘贴给任何 AI，AI 就变成你的专家团。

不需要安装、不需要数据库、不需要联网。复制文件夹 = 部署完成。

## 二、核心概念 (22 个专家)

AC 有 22 个专家，分成 4 类：

### 生活类 (10 人)
| 专家 | 什么时候找他 |
|------|-------------|

## 三、调度规则 (AI 怎么找到对应专家)

AI 不是同时让 22 个专家说话，而是按规则唤醒：

### 唤醒规则
```
你说一句话 → AI 扫描关键词 → 匹配到哪个专家 → 唤醒他
                                   ↓
                            如果没匹配到 → AI 自己回答 (兜底)
```

### 冲突规则
如果一句话同时命中多个专家（比如"老板欠我工资，我很焦虑"同时命中劳动权益和心理医生）：

| 优先级 | 类型 | 谁先上 |
|--------|------|--------|
| P1 | 安全/生存 | 危机预案、反诈骗、临床审查、法律顾问 |
| P2 | 权益/合规 | 劳动权益、行政向导、个人财务 |
| P3 | 心理/健康 | 心理医生、健康顾问 |
| P4 | 技术/决策 | 架构审计、代码审查、合伙挑刺 |
| P5 | 通用/辅助 | 百科全书、学习教练、数据整理 |

**规则**: 安全先于情绪。有违法行为先讲法律，不讲安慰。

### 租约规则
```
专家被唤醒 → 保持 3 轮对话 (心理医生 5 轮)
3 轮内继续追问 → 续期 2 轮
3 轮内没说话 → 自动休眠，让出上下文空间
```

### 升级通道
```
心理医生发现身体症状 → 自动唤醒健康顾问
反诈骗发现已经转账 → 自动唤醒危机预案 (黄金 30 分钟)
劳动权益涉及复杂法条 → 自动唤醒法律顾问
```

## 四、AC 怎么用

### 日常使用
```
1. 打开任意 AI (opencode / Comate / Trae / ChatGPT)
2. 粘贴 CORE-DATA.md (你的个人画像)
3. 粘贴 DYNAMIC-DATA.md (你今天的能量和状态)
4. 粘贴 SCHEDULER.md (调度规则)
5. 开始对话, AI 自动识别你的需求, 唤醒对应专家
```

### 快速命令
```
"ac status"     → 查看 AC 当前状态 (能量/最近专家/待办)
"AC 怎样？"     → 系统评估报告
"按这个执行"    → 生成原子任务列表
"变回来"        → 结束专家模式, 回到普通对话
```

## 六、设计原则

1. **零依赖** — 所有文件都是纯 Markdown，不需要任何软件
2. **复制即部署** — 把文件夹复制到 U 盘，插到任何电脑都能用
3. **AI 就是引擎** — AC 没有自己的服务端，AI 的对话窗口就是运行时
4. **确定性优先** — 能不交给 AI 判断就不交，用关键词硬匹配
5. **安全 > 情绪** — 先处理风险，再安抚心情
6. **22 人上限** — 每加一个新专家，就要考虑删一个不用的
