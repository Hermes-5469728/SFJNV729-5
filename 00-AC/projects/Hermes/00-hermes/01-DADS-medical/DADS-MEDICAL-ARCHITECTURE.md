# DADS 医疗版 (DADS-Medical) 产品架构

## 定位

面向临床医生的智能诊断辅助系统。**1+N 轨道**中作为 `ac-core/BaseAgent` 的垂直插件运行；**独立产品轨道**中作为可独立部署的完整诊断产品。

---

## 一、1+N 轨道 — 垂直插件

### 代码位置
```
AgentHub/dads-medical/
├── __init__.py          # 统一导出
├── diagnosis.py         # MedicalDiagnosis(BaseAgent) — diagnose() / _analyze()
└── knowledge_base.py    # query_medical_knowledge() — 10种疾病KB
```

### 调用链
```
main.py
  └→ MedicalDiagnosis.diagnose(symptoms)
       ├→ think(symptoms)                    # 继承自 BaseAgent
       │    ├→ query_medical_knowledge()     # 查询知识库
       │    ├→ TaskPlanner.decompose()       # 任务拆解
       │    └→ ShortTermMemory.add()         # 记忆记录
       └→ _analyze(symptoms)                # 知识库匹配
            ├→ 症状 token 化
            ├→ 与 MEDICAL_KB (10条) 匹配评分
            └→ 返回: disease / severity / confidence / advice
```

### 知识库规模

| 严重程度 | 疾病数 | 示例 |
|---|---|---|
| 🔴 危重 (critical) | 3 | AML, ALL, 急性心肌梗死 |
| 🟠 重度 (severe) | 2 | 重症肺炎/脓毒症, 糖尿病酮症酸中毒 |
| 🟡 中度 (moderate) | 3 | 社区获得性肺炎, 缺铁性贫血, 原发性高血压 |
| 🟢 轻度 (mild) | 2 | 急性上呼吸道感染, 急性胃肠炎 |

### 匹配算法
```
score = 0.6 × (匹配症状数/疾病总症状数) + 0.4 × (匹配症状数/输入症状数)
       → 按分排序 → 取最佳匹配 → 多匹配时置信度×0.85
```

## 二、独立产品轨道 — DADS 医疗版 (独立部署)

### 架构
```
┌─────────────────────────────────────────┐
│          DADS 医疗版                     │
├─────────────┬─────────────┬─────────────┤
│ 临床决策    │ 诊断辅助    │ 治疗方案    │
│ 支持 (DM1)  │ 系统 (DM2)  │ 推荐 (DM3)  │
├─────────────┴─────────────┴─────────────┤
│     风险评估模块 (DM4)                   │
├─────────────────────────────────────────┤
│          通用数据中心                    │
└─────────────────────────────────────────┘
```

### 独立部署时扩展的目录
```
dads-medical/
├── models/           # 深度学习诊断模型
├── imaging/          # 影像辅助诊断
├── lab/              # 检验结果解读
├── treatment/        # 治疗方案推荐引擎
├── risk/             # 并发症风险预测
├── api/              # REST API 层
└── web/              # Web 前端 (医生工作站)
```

### V1.0 → V2.0 升级路线

| 版本 | 能力 | 状态 |
|---|---|---|
| V1.0 | 规则匹配诊断 (10 种疾病 KB) | 已交付 |
| V1.5 | 扩展 KB 至 50+ 疾病，接入 Hermes 数据中心真实 API | 待开发 |
| V2.0 | 接入检验/影像数据，多模态诊断，独立 Web 部署 | 待规划 |
