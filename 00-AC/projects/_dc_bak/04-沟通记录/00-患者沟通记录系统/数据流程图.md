## 二、核心数据流程

### 1. 用户数据录入流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant API as API网关
    participant Service as 业务服务
    participant Validator as 数据验证器
    participant DB as 数据库
    participant File as 文件存储
    
    User->>API: 提交数据
    API->>Service: 转发请求
    Service->>Validator: 数据验证
    alt 验证通过
        Validator-->>Service: 验证成功
        Service->>DB: 存储结构化数据
        DB-->>Service: 存储成功
        Service->>File: 存储附件文件
        File-->>Service: 存储成功
        Service-->>API: 返回成功
        API-->>User: 200 OK
    else 验证失败
        Validator-->>Service: 验证失败
        Service-->>API: 返回错误
        API-->>User: 400 Bad Request
    end
```

### 2. 知识检索流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant API as API网关
    participant Search as 检索服务
    participant Vector as 向量索引
    participant DB as 数据库
    participant Doc as 文档存储
    
    User->>API: 检索请求
    API->>Search: 处理检索
    Search->>Vector: 语义匹配
    Vector-->>Search: 匹配结果
    Search->>DB: 获取元数据
    DB-->>Search: 元数据
    Search->>Doc: 获取文档内容
    Doc-->>Search: 文档内容
    Search-->>API: 检索结果
    API-->>User: 返回文档列表
```

### 3. 数据备份流程

```mermaid
graph TD
    A[定时任务触发] --> B[连接数据库]
    B --> C[执行备份命令]
    C --> D[生成备份文件]
    D --> E[压缩加密]
    E --> F[存储到备份目录]
    F --> G[记录备份日志]
    G --> H[发送通知]
```

## 三、数据流向矩阵

| 数据类型 | 来源 | 处理 | 存储 | 输出 |
|----------|------|------|------|------|
| 用户数据 | 前端表单 | 验证清洗 | SQLite | API响应 |
| 知识文档 | 上传/导入 | 解析索引 | 文件系统+向量库 | 检索结果 |
| 系统日志 | 应用运行 | 格式化 | 文件日志 | 监控面板 |
| 配置数据 | 管理员配置 | 校验 | 配置文件 | 应用读取 |
