# 意图卡 · AC 学习路径 · 助手带我学

## 目标
将 AC 系统的架构盲区转化为可执行的、由 AI 助手驱动的学习课程。每节课 = 一张意图卡 + 一个可运行的验证命令。用户不谈理论，只看代码和测试。

## 设计原则
1. **学习发生在实现中** — 不讲原理，只讲"这个模块解决什么问题 → 改哪段代码 → 怎么验证"
2. **每节课 30 分钟内完成** — 用户打开 IDE，AI 助手引导，改代码，跑测试，看到 PASS
3. **失败即教科书** — 如果 ArchGuard 报 FAIL，助手不是修复它，而是解释"为什么这个 FAIL 恰好证明了我们在学的那类问题"
4. **零理论灌输** — 如果一段概念可以用一段运行的代码替代，就不要用文字

## 第一模块：工程意识（5 课）

### 第 1 课 · CI/CD 流水线
- **意图卡**: `意图卡_CI_CD流水线.md`
- **学什么**: 自动化门禁——代码变了自动跑测试
- **动手**: 写 `.git/hooks/pre-commit`，每次 commit 前自动 `python run_tests.py`
- **验证**: 故意写一个会失败的测试，看 commit 是否被拦截
- **助手角色**: 解释"为什么手动测试不可靠"

### 第 2 课 · 优雅降级与超时
- **意图卡**: `意图卡_优雅降级与熔断.md`
- **学什么**: 外部依赖挂掉时系统如何体面死而不是爆炸
- **动手**: 给 `deepseek_free.py` 的 API 调用加 `@circuit_breaker(timeout=10000)`
- **验证**: 断开网络，看 dispatch 是抛异常还是优雅返回"模型不可用"
- **助手角色**: 解释"超时和熔断有什么区别，为什么两个都要"

### 第 3 课 · 灰度发布
- **意图卡**: 待生成 (Opencode)
- **学什么**: 新代码不是全量替换，而是先切 10% 流量验证
- **动手**: 在 `ac_server.py` 加 `/api/canary` 端点，返回新旧两个版本的对比
- **验证**: 同时访问 canary 和 production，对比输出
- **助手角色**: 解释"为什么不能直接 commit 然后祈祷"

### 第 4 课 · SRE 可观测性
- **意图卡**: 待生成 (Opencode)
- **学什么**: 日志、指标、追踪三合一——不用 grep 定位问题
- **动手**: 给所有 `_log.error()` 加 `trace_id`，用 `governance_events` 表关联
- **验证**: 制造一个错误，用一条 SQL 查询从入口到报错的完整链路
- **助手角色**: 解释"没有 trace_id 的日志只是文字，有了才是故事"

### 第 5 课 · 负载测试
- **意图卡**: 待生成 (Opencode)
- **学什么**: 系统能扛多少并发？瓶颈在哪？
- **动手**: 写一个简单的压测脚本，10 个并发 dispatch 请求
- **验证**: 找到第一个报错的并发数，定位瓶颈（SQLite 写锁？API rate limit？）
- **助手角色**: 解释"雪崩效应——一个慢请求如何拖垮整个系统"

## 第二模块：编程意识（4 课）

### 第 6 课 · 类型安全
- **意图卡**: 待生成 (Opencode)
- **学什么**: Python 的类型注解不是装饰——mypy 可以在运行时之前拦截类型错误
- **动手**: 给 `core.py:dispatch()` 加完整类型注解，运行 `mypy ac/`
- **验证**: 故意传给 dispatch 一个 int 而非 str，看 mypy 是否报错
- **助手角色**: 解释"动态类型 = 把错误推迟到运行时，静态检查 = 把错误杀死在写代码时"

### 第 7 课 · 并发安全
- **意图卡**: 待生成 (Opencode)
- **学什么**: SQLite 的 WAL 模式如何处理多读单写——以及什么情况下会死锁
- **动手**: 写两个线程同时调 `guard.store_truth()`，观察 WAL 日志
- **验证**: 用 `PRAGMA wal_checkpoint` 确认无锁竞争
- **助手角色**: 解释"SQLite 不是玩具数据库，但不配置 WAL 就是"

### 第 8 课 · 资源管理
- **意图卡**: 待生成 (Opencode)
- **学什么**: 文件句柄、数据库连接、线程池——不用时不关，系统会偷偷崩
- **动手**: 给 `knowledge_service.py` 的 `_conn()` 加 `try/finally` 和连接池上限
- **验证**: 连续调 1000 次 search，看内存和文件句柄是否线性增长
- **助手角色**: 解释"Python 的 GC 不可靠——它只回收内存，不回收文件句柄"

### 第 9 课 · 错误分层
- **意图卡**: 待生成 (Opencode)
- **学什么**: 业务异常、系统异常、网络异常不能混在同一个 `except Exception`
- **动手**: 创建 `ac/exceptions.py`，定义 `ACException` → `DispatchError` / `ModelTimeout` / `DBLockError`
- **验证**: 在不同层抛出不同异常，看日志中能否区分根因
- **助手角色**: 解释"catch Exception 等于对医生说'我不舒服'——医生没法诊断"

## 第三模块：架构意识（5 课）

### 第 10 课 · ADR 架构决策记录
- **意图卡**: `意图卡_ADR架构决策记录.md`
- **学什么**: 为什么选 A 不选 B——这个"为什么"比"选了什么"更有价值
- **动手**: 补写 ADR-001（为什么用 SQLite），ADR-002（为什么 ChromaDB 而非 Pinecone）
- **验证**: 跑 `python -c "from ac.truth import get_truth; print(get_truth('ADR-001'))"` 能返回决策记录
- **助手角色**: 解释"代码告诉你 what，ADR 告诉你 why——3 个月后你就是那个问 why 的人"

### 第 11 课 · 宪法修订程序
- **意图卡**: 待生成 (Opencode)
- **学什么**: R10 是怎么加进宪法的？下次加 R13 时流程是什么？
- **动手**: 给 `CORE_PHILOSOPHY.md` 加修订程序章节，定义提议→模拟→投票→生效四步
- **验证**: 模拟一次修宪：写一条 R13 草案，走流程，看是否能被不合理的提案绕过
- **助手角色**: 解释"宪法不是写出来的——是修出来的。修宪程序比宪法本身更重要"

### 第 12 课 · 多租户隔离
- **意图卡**: 待生成 (Opencode)
- **学什么**: 你的 Jarvis 记忆库和别人的记忆库如何物理隔离
- **动手**: 给 `ac_platform.db` 的每张表加 `user_id` 列，改所有查询加 `WHERE user_id=?`
- **验证**: 用 user_id="alice" 写入数据，用 user_id="bob" 查询，确认看不到 alice 的数据
- **助手角色**: 解释"SQLite 单文件 = 天然隔离难。多租户的第一步是每行数据知道它属于谁"

### 第 13 课 · 韧性架构
- **意图卡**: 待生成 (Opencode)
- **学什么**: 部分模块失效时，系统如何继续提供降级服务
- **动手**: 写一个 `health_check()` 聚合器，检测 7 个模块的存活状态
- **验证**: 关掉 ChromaDB，看 knowledge_service 是否能自动切到纯 truth 模式
- **助手角色**: 解释"高可用不是'永远不挂'——是'挂了也能跑'"

### 第 14 课 · 分布式共识雏形
- **意图卡**: `意图卡_分布式共识雏形.md`
- **学什么**: 5 个 AI 给出矛盾的答案时，怎么不靠人工判断谁更可信
- **动手**: 用 dual_inference 的双实例输出 + 多模型语义嵌入，检测哪些词句模型间一致、哪些分歧
- **验证**: 输入"布洛芬对孕妇安全吗"，看共识层能否标出"所有模型都说慎用，但理由不同"
- **助手角色**: 解释"共识不是投票——一个专家说'有毒'，一万个路人说'没事'，你不能取平均数"

## 使用方式

### 用户对助手说
```
打开 00-AC/architecture/意图卡_学习路径_助手带我学.md，从第 N 课开始
```

### 助手的标准流程
```
1. 读对应意图卡
2. 解释"这课解决什么问题"（30 秒）
3. 打开要改的文件，逐段改代码
4. 每改完一段，跑一次验证命令
5. 如果 FAIL → 解释"为什么这个 FAIL 正好是我们在学的"
6. 全部 PASS → 总结"你刚学到了什么"
```

### 验收标准
每课结束时跑：
```bash
python run_tests.py        # 5/5 PASS
python -c "from archguard import get_guard; r=get_guard().full_scan(); print(r['overall'])"  # PASS
```
