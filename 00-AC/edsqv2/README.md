## 🏗️ 核心变化

### 1. 增强的 E 层（原来是只有编码检测）

| 原功能 | 新功能 |
|--------|--------|
| ✅ sanitize_text() | ✅ 保留 |
| ✅ 编码检测 | ✅ 保留 |
| ❌ 输入分类 | ✅ 新增 InputClassifier |
| ❌ 输入结构化 | ✅ 新增结构化功能 |
| ❌ 输入去重 | ✅ 新增 InputCache（TTL 30 分钟）|

### 2. 新增的 Gate 系统

| Gate | 位置 | 功能 |
|------|------|------|
| **Gate1** | E → D | 输入筛选（乱码、服务范围、缓存）|
| **Gate2** | D → S | 复杂度判断（D/S 协作）|
| **Gate3** | Q → Output | 最终检查（可插拔）|

### 3. D/S 协作（不是竞争）

```
之前：   E → D/S (二选一) → Q → Output
现在：   E → Gate1 → D → Gate2 → [S (需要时)] → Q → Gate3 → Output
```

### 4. Q 层可插拔

| 原功能 | 新功能 |
|--------|--------|
| 硬编码检查器顺序 | 可配置检查链 |
| 所有输入相同检查 | 根据类型选择（医疗用严格检查链，闲聊用轻量）|
| 不可扩展 | 支持自定义 checker 插件 |

## 🚀 使用方法

```python
from edsqv2 import EDSQv2

# 创建实例
eds = EDSQv2()

# 注册专家
eds.register_experts({
    "medical_expert": (
        lambda text: f"医学咨询: {text}",
        "处理医学问题",
        ["医疗", "健康"]
    ),
    # ... 更多专家
})

# 添加锚点
eds.add_anchor("图灵测试", "图灵测试由艾伦·图灵于1950年提出")

# 处理输入
result = eds.process("什么是高血压？")
print(result["output"])
```

## 🎯 解决的架构问题

| 原问题 | 解决方案 |
|--------|----------|
| Q 层被切成两段（只有输出有治理）| Gate1 + Gate3，输入和输出都有治理 |
| E 层太薄 | 新增分类 + 结构化 + 缓存 |
| D/S 是竞争关系 | Gate2 复杂度判断，先 D 后 S（协作模式）|
| Q 层死顺序 | 可插拔检查链 + 类型配置 |
