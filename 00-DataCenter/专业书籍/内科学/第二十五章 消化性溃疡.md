## 学习目标

1. **知识**：说出消化性溃疡的概念、临床表现、并发症及诊断要点，列举消化性溃疡的病因与发病机制，解释消化性溃疡的辅助检查和鉴别诊断。
2. **能力**：根据患者的病史、临床表现做出初步诊断，能为消化性溃疡患者提供正确的治疗策略及根除幽门螺杆菌的治疗方案。
3. **素养**：深刻认识消化性溃疡并发症的危险性（如大出血可危及生命），在诊疗过程中保持警惕，对高危患者（如老年患者、长期服用非甾体抗炎药者）进行重点监测和干预。严格遵守医疗操作规范（如胃镜检查的术前准备、术中管理、术后护理），降低医疗风险，保障患者安全。从公共卫生角度探析消化性溃疡的群体防控意义（如幽门螺杆菌的家庭聚集性传播），在临床工作中积极参与科普宣传，助力疾病的预防控制。

## 消化性溃疡概述

**消化性溃疡（peptic ulcer，PU）** 是指胃肠道黏膜发生的炎症缺损，由于胃酸、胃蛋白酶的消化作用是溃疡形成的基本因素，故称消化性溃疡。消化性溃疡常发生于胃和十二指肠球部，也可发生于食管、胃-空肠吻合口附近以及含有胃黏膜的梅克尔（Meckel）憩室。

### 流行病学

消化性溃疡是全球性常见病，可发生于任何年龄阶段，男性多于女性，约有10%的人在其一生中患过此病。十二指肠溃疡（duodenal ulcer，DU）多于胃溃疡（gastric ulcer，GU），两者发病之比约为3:1，DU多见于青壮年人，GU多见于中老年人。

### 病因与发病机制

消化性溃疡的发生机制是**损伤因素与黏膜防御因素之间失去平衡**，胃酸对黏膜自我消化。

1. **幽门螺杆菌感染**：是消化性溃疡形成的重要病因，也是消化性溃疡反复发作、迁延不愈的根本原因。主要基于：①消化性溃疡患者幽门螺杆菌检出率显著高于对照组人群；②成功根除幽门螺杆菌后有助于溃疡愈合，复发率明显下降。
2. **胃酸和胃蛋白酶**：胃酸在溃疡形成过程中起决定性作用，它是溃疡形成的直接原因。胃蛋白酶是消化性溃疡发病的另一个重要因素，其活性依赖于胃液的pH，pH为2~3时，胃蛋白酶原被激活；pH>4时，胃蛋白酶失活，因此，抑制胃酸可抑制胃蛋白酶的活性。
3. **药物**：药物所致消化性溃疡以非甾体抗炎药（NSAIDs）最常见，如布洛芬、吲哚美辛、阿司匹林，5%~30%的患者可发生消化性溃疡，主要与其抑制体内前列腺素合成，削弱其对胃、十二指肠黏膜的保护作用有关。另外，长期服用糖皮质激素、氯吡格雷、化疗药物、双膦酸盐、西罗莫司等药物易于发生消化性溃疡。
4. **其他因素**：①吸烟；②遗传；③急性应激；④胃、十二指肠运动异常。

### 病理

- **十二指肠溃疡（DU）**：多发生于十二指肠球部，以紧邻幽门的前壁或后壁常见。
- **胃溃疡（GU）**：多发生于胃角和胃窦小弯，靠近幽门腺区（胃窦）与泌酸腺区（胃体）交界处的幽门腺区一侧。幽门腺区黏膜可随年龄增长而扩大，使其与泌酸区的交界上移，故老年患者GU病变部位多较高。
- 活动期消化性溃疡一般为单个，也可为多个，呈圆形或椭圆形。直径多<10 mm，边缘较光整，底部由肉芽组织构成，表面覆以白色或黄色渗出物，溃疡周围黏膜充血、水肿。溃疡深者可达肌层或浆膜层，累及血管时引起出血，穿破浆膜层时引起穿孔。溃疡愈合后产生瘢痕，瘢痕收缩形成狭窄或假性憩室等。

### 临床表现

#### 症状

典型症状为上腹痛，性质可为钝痛、灼痛、胀痛、剧痛或饥饿样不适感。疼痛多位于中、上腹部，可偏右或偏左。特点包括：

1. **慢性病程**：可达数年至数十年。
2. **周期性发作**：发作期可为数周甚至数月，缓解期也可长短不一。发作有季节性，多在秋季、冬季或者冬春之交发病。
3. **节律性上腹痛**：GU多为餐后痛，DU多为饥饿痛或夜间痛，进餐缓解。
4. 腹痛多可被抑酸药或抗酸药缓解。

部分患者症状较轻，仅表现为上腹不适、腹胀、厌食、嗳气、反酸等。还有**无症状性溃疡**，以长期服用NSAIDs患者及老年人多见。

#### 体征

溃疡发作时上腹部可有局限性压痛，缓解期无明显体征。

#### 特殊类型溃疡

| 类型 | 特点 |
|------|------|
| **复合性溃疡** | 胃和十二指肠同时发生的活动性溃疡，多见于男性 |
| **幽门管溃疡** | 餐后很快疼痛，节律性不明显，易发生幽门梗阻、出血和穿孔 |
| **球后溃疡** | 十二指肠降段、水平段，疼痛向右上腹及背部放射，药物反应差，易出血 |
| **巨大溃疡** | 直径>2 cm，常见于服用NSAIDs的老年人 |
| **老年人溃疡** | 症状不典型，GU多位于胃体上部，易误诊为胃癌 |
| **难治性溃疡** | 经正规抗溃疡治疗而溃疡未愈合者 |

### 并发症

1. **出血**（最常见）：消化性溃疡是上消化道大出血最常见的病因（约占50%）。DU较GU更易发生出血。表现为呕血和（或）黑便。
2. **穿孔**：急性穿孔多发生于十二指肠前壁或胃前壁，引起急性弥漫性腹膜炎。
3. **幽门梗阻**：2%~4%的病例，主要由十二指肠球部溃疡或幽门管溃疡引起。呕吐物含发酵的酸性宿食，振水音阳性。
4. **癌变**：DU一般不发生癌变。反复发作、病程长的GU癌变概率增加。

### 辅助检查

1. **胃镜及胃黏膜活检**（首选/金标准）：可明确有无溃疡、部位、分期（A活动期/H愈合期/S瘢痕期），活检鉴别良恶性，镜下止血。
2. **X线钡餐检查**：龛影为直接征象（确诊价值），间接征象提示可能。
3. **CT检查**：对穿透性溃疡或穿孔有价值。
4. **幽门螺杆菌检测**
5. **粪便隐血试验**：了解是否合并出血。
6. **胃液分析和血清促胃液素测定**

### 诊断

根据慢性病程、周期性发作、节律性疼痛等典型临床表现，结合胃镜或X线钡餐检查见龛影可确诊。

### 鉴别诊断

应与胃癌、慢性胃炎、慢性胆囊炎、胃神经官能症等疾病鉴别。

### 治疗

治疗目的：消除病因、缓解症状、愈合溃疡、防止复发和防治并发症。

1. **一般治疗**：生活规律，戒烟酒，避免辛辣刺激食物。停用NSAIDs。
2. **药物治疗**：H₂受体拮抗剂、质子泵抑制剂（PPI）、根除幽门螺杆菌治疗、胃黏膜保护剂。
