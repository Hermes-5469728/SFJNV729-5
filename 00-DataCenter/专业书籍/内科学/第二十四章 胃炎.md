## 学习目标

1. **知识**：说出胃炎的定义、分类及临床意义，列举常见的胃炎类型及其病因，解释胃炎的病理生理机制，分析胃炎的临床表现、诊断方法及治疗原则。
2. **能力**：完成胃炎患者的病史采集和体格检查，运用病史、体格检查及辅助检查结果对胃炎做出初步诊断，根据胃炎的类型和严重程度制定相应的治疗方案，解释胃炎的预防措施，实施健康教育。
3. **素养**：对胃炎患者的病情变化保持警惕（如慢性萎缩性胃炎患者需定期随访以防癌变）；对治疗效果负责，主动跟踪患者用药依从性与症状改善情况，及时调整干预策略。耐心倾听患者对症状的描述，理解其因疾病带来的生活困扰（如影响睡眠、社交），缓解其心理压力。如实告知患者病情（如萎缩性胃炎的癌变风险），不隐瞒、不夸大；拒绝过度医疗（如不必要的胃镜复查、高价保健品推荐），为患者提供精准、安全、有温度的医疗服务，同时推动胃炎诊疗领域的科学进步。

## 概述

**胃炎（gastritis）** 是指由各种病因引起的胃黏膜炎症。根据发病情况，一般将胃炎分为常见的急性胃炎与慢性胃炎和少见的特殊类型胃炎。

---

## 第一节 急性胃炎

**急性胃炎（acute gastritis）** 是指由多种病因引起的胃黏膜急性炎症。胃黏膜充血、水肿、表面糜烂渗出物称为**急性单纯性胃炎**；胃黏膜病变以糜烂和出血为主，称为**急性糜烂出血性胃炎**，又称急性胃黏膜病变。一般短期内可治愈，极少数可演变为慢性胃炎。

### 病因与发病机制

| 病因 | 机制 |
|------|------|
| **理化刺激** | 过冷过热粗糙食物、暴饮暴食；NSAIDs（阿司匹林等）抑制COX→前列腺素E↓→黏膜修复障碍 |
| **应激** | 严重创伤/手术/烧伤/颅内病变→黏膜微循环障碍→缺血缺氧→糜烂出血 |
| **十二指肠-胃反流** | 胆汁、肠液、胰液反流入胃→黏膜糜烂出血 |
| **感染** | 细菌病毒毒素（大肠埃希菌、葡萄球菌）；急性化脓性胃炎（少见但严重） |
| **血液循环障碍** | 门静脉高压→门静脉高压性胃病 |

### 临床表现

上腹不适、腹痛、胀满、恶心、呕吐、食欲缺乏；严重者呕血、黑便、脱水、酸中毒、休克。NSAIDs导致者多无症状。细菌/病毒污染食物者：进食后6~24h发病，伴腹泻。

> 考点提示：急性胃炎的症状。

---

## 第二节 慢性胃炎

**慢性胃炎（chronic gastritis）** 是由各种病因引起的胃黏膜慢性炎症，胃黏膜呈非糜烂的炎性改变。发病率随年龄增长而增加。**Hp感染是最常见的病因**。胃镜+活检病理是诊断与鉴别诊断的主要手段。

**分类：**
- 按病因：Hp感染性胃炎 / 非Hp感染性胃炎
- 按分布：胃窦炎 / 胃体炎 / 全胃炎
- 按病理：非萎缩性（浅表性）胃炎 / 萎缩性胃炎

### 病因与发病机制

1. **幽门螺杆菌（Hp）感染**（最主要病因）：Hp产生尿素酶→分解尿素产氨→形成局部微环境→逃避胃酸杀灭→慢性感染。Hp毒力、宿主差异、微生态环境决定转归。
2. **十二指肠液反流**：胆汁、胰液反流→损伤黏膜屏障
3. **药物和酒精**：NSAIDs、饮酒→黏膜损害
4. **自身免疫**：壁细胞/内因子自身抗体→壁细胞↓→胃酸↓、内因子↓→维生素B₁₂吸收不良→恶性贫血
5. **其他**：遗传易感性、过冷过热粗糙食物、浓茶咖啡、高盐饮食等

### 病理

**非萎缩性胃炎**：病变局限黏膜上1/3，腺体正常。
**萎缩性胃炎**：黏膜萎缩变薄，腺体破坏消失。

**组织学变化（4项）：**

| 变化 | 描述 |
|------|------|
| **炎症** | 淋巴细胞、浆细胞浸润，活动期见中性粒细胞 |
| **萎缩** | 腺体破坏减少，固有层纤维化；多灶萎缩→胃癌风险↑ |
| **上皮化生** | 肠上皮化生（杯状细胞）或假幽门腺化生 |
| **异型增生** | 低级别（轻中度）→高级别（重度+原位癌）= 癌前病变 |

**胃癌前情况：**
- **癌前状态（胃癌前疾病）**：慢性萎缩性胃炎、胃息肉、胃溃疡、残胃
- **癌前病变**：萎缩、肠上皮化生、异型增生

### 临床表现

大多无特异性症状：中上腹不适、饱胀、隐痛、嗳气、反酸、食欲缺乏等。**症状轻重与胃镜病理所见不成比例**。胃体萎缩性胃炎：厌食、消瘦、缺铁性贫血，少数恶性贫血。体征：上腹部轻压痛。

### 诊断

疑诊→确诊依靠**胃镜检查**（可见糜烂出血病灶+病理组织学检查）。因胃黏膜修复快，应尽早胃镜。

### 治疗

1. **一般治疗**：去除病因，治疗原发病。不能停用NSAIDs者用H₂受体拮抗药/PPI/前列腺素预防。
2. **药物治疗**：
   - 抑酸：H₂受体拮抗药（西咪替丁）、PPI（奥美拉唑）
   - 保护胃黏膜：硫糖铝、L-谷氨酰胺呱仑酸钠颗粒
   - 局部止血：凝血酶、云南白药、去甲肾上腺素口服

---

*考点速记*
- 急性胃炎病因：理化/应激/反流/感染/循环障碍
- 慢性胃炎最主要病因：Hp感染
- 慢性胃炎分类：非萎缩性 vs 萎缩性
- 癌前病变：萎缩→肠化→异型增生（上皮内瘤变）
- 确诊手段：胃镜+活检病理
- 症状 ≠ 病理严重程度（症状轻≠病变轻）

---

## 辅助检查

1. **胃镜及活体组织检查**（最可靠诊断方法）：活检宜多部位取材，标本量要足够（达黏膜肌层）。
2. **幽门螺杆菌检测**：
   - 侵入性（需胃镜活检）：快速尿素酶试验、组织学检查、Hp培养
   - 非侵入性：¹³C/¹⁴C尿素呼气试验、粪便Hp抗原检测、血清学检查（抗Hp IgG抗体）
3. **自身免疫性胃炎相关检查**：血清壁细胞抗体（PCA）、内因子抗体（IFA）、维生素B₁₂水平

> **考点提示**：慢性胃炎的临床表现——非特异性上腹痛、非节律性。

## 对因治疗（重点）

### 幽门螺杆菌根除——铋剂四联方案
**1种PPI + 1种铋剂 + 2种抗生素，疗程10~14d**

| 药物类别 | 代表药物 |
|---------|---------|
| **PPI** | 埃索美拉唑、奥美拉唑、兰索拉唑、泮托拉唑、雷贝拉唑、艾普拉唑 |
| **铋剂** | 枸橼酸铋钾、果胶铋 |
| **抗生素** | 克拉霉素、阿莫西林、甲硝唑、替硝唑、喹诺酮类、呋喃唑酮、四环素 |

### 其他对因治疗
- 十二指肠液反流：改善胃肠动力药物
- 胃黏膜营养因子缺乏：补充复合维生素，恶性贫血者终身注射维生素B₁₂

### 对症治疗
- **抑酸药**：H₂受体拮抗药（西咪替丁、雷尼替丁、法莫替丁）、PPI（奥美拉唑等）
- **胃黏膜保护药**：硫糖铝、枸橼酸铋钾
- **助消化药**：干酵母、复方消化酶、多潘立酮、莫沙必利

## 癌前情况治疗

| 程度 | 处理 |
|------|------|
| **轻中度异型增生** | 可逆→根除Hp+补充复合维生素+富硒药物 |
| **重度异型增生** | 内镜下剥离术+定期随访 |

### 案例分析

患者女性52岁，反复上腹部疼痛（夜间），食欲缺乏、体重减轻。上腹部轻压痛。胃镜示胃窦黏膜糜烂和红斑。

**初步诊断**：慢性胃炎（胃窦炎，伴糜烂）
**治疗原则**：①根除Hp（如阳性）；②PPI抑酸；③胃黏膜保护剂；④饮食调整，规律作息
