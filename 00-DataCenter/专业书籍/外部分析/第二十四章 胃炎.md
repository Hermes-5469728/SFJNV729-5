## 一、急性胃炎常见病因

### NSAIDs（核心病因）
- 抑制COX活性 → 前列腺素合成↓ → 胃黏膜屏障削弱 → 急性糜烂出血性胃炎
- 约占药物相关胃炎的50%以上

### Hp感染与急性胃炎
- Hp初次感染可致急性胃炎（上腹痛、恶心、呕吐、短暂黏膜糜烂）
- 高毒力菌株或免疫应答剧烈时更明显
- 修正：Hp不"仅归属慢性胃炎"，其急性致病性已被临床证实

### 其他病因
- 饮食不当（酒精、刺激性食物）
- 应激状态（严重创伤、大手术）

## 二、胃镜与病理诊断

| 要点 | 内容 |
|------|------|
| 胃镜时机 | 急性胃炎需**24~48h内**完成，否则黏膜修复影响诊断 |
| 急性期所见 | 充血、水肿、糜烂、出血灶 |
| 活动性标志 | **中性粒细胞浸润**（区别于慢性静止期的淋巴细胞） |
| Hp活动性 | 病理报告常同时描述中性粒细胞浸润程度+Hp密度 |

## 三、特殊类型胃炎

### 自身免疫性胃炎（A型胃炎）
- PCA阳性率>90%，IFA阳性进一步支持
- 机制：PCA攻击壁细胞 → 内因子↓ → B₁₂吸收障碍 → 大细胞性贫血
- 治疗：必须补B₁₂（肌注/高剂量口服），单纯补铁无效

### Hp根除
- 铋剂四联（PPI+铋+2种抗生素，10~14d）为一线方案
- 根除可降低进展风险，但对已存在的萎缩/肠化无逆转作用
