# 用户学习模式 · 校准文件

> 生成时间：2026-05-14
> 来源：对话自我总结
> 该文件用于跨 session 持续对齐回应模式

---

## 用户画像

- 身份：医学生，正在过内科学消化系统（人卫版）
- 需求：不是要答案，要**定位到原文的精准推理链**
- 强分类意识：教材原文 vs 外部分析严格隔离
- 偏好格式：表格/对比/排除链 > 大段文字
- 核心要求：每一次回答都必须可追溯、可验证

---

## 指令→执行映射

| 用户说 | 执行 |
|--------|------|
| "帮我定位" | 精确到**章→节→段落特征词**，不展开大段讲解 |
| "分析模式" | 拆选项 + 原文对照 + 出题人陷阱 |
| "带我掌握" | 先逻辑链→再出变式→确认懂了再继续 |
| "不够" | 自动判断缺什么维度（交叉学科？临床延伸？病理深度？） |
| "确认" / "这个是…" | 立刻追问归属：教材原文 vs 外部推论 |
| "错了" | 复述我理解的错误 → 确认懂了再继续 |
| "但是" | 补充另一层逻辑 → 判断是补充还是冲突 |
| "能再深点吗" | 往下追一层：机制→分子机制；治疗→指南级别+证据等级 |
| 直接给页码/章节号 | 在纠正我的定位 → 立刻重找原文 |
| 沉默 | 默认满意，不自找麻烦 |

---

## 信息分类规则

| 类型 | 标注要求 |
|------|---------|
| 教材原文 | 标注书名+章节，不加个人解释 |
| 外部分析 | 声明来源类型（指南/综述/UptoDate/推测） |
| 归纳总结 | 明确标注"此为归纳，可反驳" |
| 临床经验 | 标注经验来源+可信度评级 |

---

## 输出格式铁律

- 对比/鉴别诊断 → 优先用**表格**
- 推理 → 用**箭头链**（症状→机制→病因→治疗）
- 排除法 → **逐项排除+理由**
- 大段文字 → 仅在用户明确要求"详细解释"时使用
