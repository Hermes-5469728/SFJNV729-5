## 二、数据处理链详细流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                   Data Pipeline Flow · 数据处理链详细流程                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  Step 0: Input                                                             │
│  ┌─────────────────────────────────────────────────────────────┐           │
│  │  数据源类型:                                                  │           │
│  │  • CLI Input (命令行输入)                                     │           │
│  │  • File Upload (文件上传)                                     │           │
│  │  • API Response (API响应)                                     │           │
│  │  • Database Query (数据库查询)                                │           │
│  │  • Message Queue (消息队列)                                   │           │
│  └─────────────────────────────────────────────────────────────┘           │
│                              │                                              │
│                              ▼                                              │
│  Step 1: Parser                                                            │
│  ┌─────────────────────────────────────────────────────────────┐           │
│  │  解析器类型:                                                  │           │
│  │  • JSONParser → 解析JSON格式                                  │           │
│  │  • YAMLParser → 解析YAML格式                                  │           │
│  │  • XMLParser → 解析XML格式                                   │           │
│  │  • CSVParser → 解析CSV格式                                   │           │
│  │  • TextParser → 解析纯文本                                   │           │
│  │                                                             │           │
│  │  输出: ParsedData { raw, format, metadata }                   │           │
│  └─────────────────────────────────────────────────────────────┘           │
│                              │                                              │
│                              ▼                                              │
│  Step 2: Cleaner                                                           │
│  ┌─────────────────────────────────────────────────────────────┐           │
│  │  清洗操作:                                                    │           │
│  │  • remove_nulls() → 删除空值                                 │           │
│  │  • remove_duplicates() → 去重                               │           │
│  │  • trim_whitespace() → 去除空白字符                           │           │
│  │  • normalize_case() → 大小写规范化                            │           │
│  │  • remove_special_chars() → 去除特殊字符                      │           │
│  │                                                             │           │
│  │  输出: CleanData { cleaned, removed_count, warnings }         │           │
│  └─────────────────────────────────────────────────────────────┘           │
│                              │                                              │
│                              ▼                                              │
│  Step 3: Validator                                                         │
│  ┌─────────────────────────────────────────────────────────────┐           │
│  │  验证类型:                                                    │           │
│  │  • SchemaValidation → Pydantic Schema验证                    │           │
│  │  • TypeValidation → 类型检查                                │           │
│  │  • RangeValidation → 范围检查                                │           │
│  │  • FormatValidation → 格式检查 (email/phone/url)             │           │
│  │  • BusinessRuleValidation → 业务规则验证                     │           │
│  │                                                             │           │
│  │  输出: ValidationResult { passed, errors, warnings }         │           │
│  └─────────────────────────────────────────────────────────────┘           │
│                              │                                              │
│                              ▼                                              │
│  Step 4: Normalizer                                                        │
│  ┌─────────────────────────────────────────────────────────────┐           │
│  │  标准化操作:                                                  │           │
│  │  • date_normalize() → 日期格式统一                           │           │
│  │  • number_normalize() → 数字格式统一                         │           │
│  │  • string_normalize() → 字符串编码统一                       │           │
│  │  • unit_normalize() → 单位统一                               │           │
│  │  • locale_normalize() → 区域设置统一                         │           │
│  │                                                             │           │
│  │  输出: NormalizedData { normalized, transformations }        │           │
│  └─────────────────────────────────────────────────────────────┘           │
│                              │                                              │
│                              ▼                                              │
│  Step 5: Enricher                                                          │
│  ┌─────────────────────────────────────────────────────────────┐           │
│  │  增强操作:                                                    │           │
│  │  • add_metadata() → 添加元数据                               │           │
│  │  • resolve_references() → 解析引用                           │           │
│  │  • enrich_with_external() → 外部数据增强                     │           │
│  │  • compute_derived() → 计算派生字段                          │           │
│  │  • add_timestamps() → 添加时间戳                             │           │
│  │                                                             │           │
│  │  输出: EnrichedData { enriched, sources, derived }           │           │
│  └─────────────────────────────────────────────────────────────┘           │
│                              │                                              │
│                              ▼                                              │
│  Step 6: Transformer                                                       │
│  ┌─────────────────────────────────────────────────────────────┐           │
│  │  转换操作:                                                    │           │
│  │  • field_mapping() → 字段映射                                │           │
│  │  • data_aggregation() → 数据聚合                             │           │
│  │  • data_filtering() → 数据过滤                               │           │
│  │  • data_pivoting() → 数据透视                               │           │
│  │  • format_conversion() → 格式转换                            │           │
│  │                                                             │           │
│  │  输出: TransformedData { transformed, mapping }              │           │
│  └─────────────────────────────────────────────────────────────┘           │
│                              │                                              │
│                              ▼                                              │
│  Step 7: Encoder                                                           │
│  ┌─────────────────────────────────────────────────────────────┐           │
│  │  编码操作:                                                    │           │
│  │  • json_encode() → JSON编码                                  │           │
│  │  • base64_encode() → Base64编码                              │           │
│  │  • hash_encode() → 哈希编码                                  │           │
│  │  • encrypt() → 加密                                          │           │
│  │  • compress() → 压缩                                          │           │
│  │                                                             │           │
│  │  输出: EncodedData { encoded, encoding_type, checksum }       │           │
│  └─────────────────────────────────────────────────────────────┘           │
│                              │                                              │
│                              ▼                                              │
│  Step 8: Quality Gate                                                      │
│  ┌─────────────────────────────────────────────────────────────┐           │
│  │  质量检查:                                                    │           │
│  │  • completeness_check() → 完整性检查                         │           │
│  │  • consistency_check() → 一致性检查                          │           │
│  │  • accuracy_check() → 准确性检查                             │           │
│  │  • uniqueness_check() → 唯一性检查                           │           │
│  │  • validity_check() → 有效性检查                             │           │
│  │                                                             │           │
│  │  输出: GateResult { passed, score, report, action }          │           │
│  └─────────────────────────────────────────────────────────────┘           │
│                              │                                              │
│                              ▼                                              │
│  Step 9: Repository (入库)                                                 │
│  ┌─────────────────────────────────────────────────────────────┐           │
│  │  存储目标:                                                    │           │
│  │  • SQLite → 关系型数据库                                     │           │
│  │  • ChromaDB → 向量数据库                                     │           │
│  │  • FileSystem → 文件系统                                     │           │
│  │  • MessageQueue → 消息队列                                   │           │
│  │  • ExternalAPI → 外部API                                     │           │
│  │                                                             │           │
│  │  输出: StorageResult { success, id, location, latency }      │           │
│  └─────────────────────────────────────────────────────────────┘           │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 九、数据处理链组件结构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    Pipeline Components · 处理链组件结构                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                          Pipeline                                   │   │
│  │                                                                      │   │
│  │  class Pipeline:                                                    │   │
│  │    ├── stages: List[Stage]        # 阶段列表                        │   │
│  │    ├── config: Dict               # 配置                            │   │
│  │    ├── metrics: PipelineMetrics   # 指标                            │   │
│  │    └── error_handler: ErrorHandler # 错误处理                      │   │
│  │                                                                      │   │
│  │    async def run(data):            # 执行管道                        │   │
│  │      for stage in stages:          # 遍历阶段                        │   │
│  │        data = await stage.process(data)                             │   │
│  │      return data                                                   │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                          Stage                                      │   │
│  │                                                                      │   │
│  │  class Stage:                                                       │   │
│  │    ├── name: str                   # 阶段名称                        │   │
│  │    ├── processor: Processor        # 处理器                          │   │
│  │    ├── config: Dict               # 配置                            │   │
│  │    ├── enabled: bool               # 是否启用                        │   │
│  │    └── skip_on_error: bool        # 错误时跳过                      │   │
│  │                                                                      │   │
│  │    async def process(data):        # 处理数据                        │   │
│  │      try:                                                          │   │
│  │        return await self.processor.execute(data, self.config)       │   │
│  │      except Exception as e:                                         │   │
│  │        if self.skip_on_error:                                       │   │
│  │          return data                                                │   │
│  │        raise                                                       │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                        PipelineMetrics                              │   │
│  │                                                                      │   │
│  │  class PipelineMetrics:                                             │   │
│  │    ├── total_items: int            # 总处理数                        │   │
│  │    ├── passed_items: int           # 通过数                          │   │
│  │    ├── failed_items: int           # 失败数                          │   │
│  │    ├── elapsed_seconds: float      # 总耗时                          │   │
│  │    ├── stage_metrics: Dict         # 各阶段指标                      │   │
│  │    └── error_counts: Dict          # 错误统计                        │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                        ErrorHandler                                │   │
│  │                                                                      │   │
│  │  class ErrorHandler:                                               │   │
│  │    ├── max_retries: int            # 最大重试次数                    │   │
│  │    ├── retry_delay: float          # 重试延迟                        │   │
│  │    ├── fallback_strategy: Callable # 降级策略                      │   │
│  │    └── log_level: str             # 日志级别                        │   │
│  │                                                                      │   │
│  │    async def handle(error, data):  # 处理错误                        │   │
│  │      for attempt in range(max_retries):                             │   │
│  │        try:                                                        │   │
│  │          return await self.retry(data)                              │   │
│  │        except:                                                     │   │
│  │          await asyncio.sleep(retry_delay * (2**attempt))           │   │
│  │      return await self.fallback_strategy(error, data)              │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
