
## 三、调度规则 (什么时候叫谁)

AI 不是让 23 个人同时说话。它按规则来:

```
我说一句话 → AI 扫关键词 → 匹配到谁 → 叫谁

如果同时命中好几个人:
  P1 安全类 > P2 权益类 > P3 心理类 > P4 技术类 > P5 通用类
  有安全风险时不先讲情绪

租约:
  叫醒后默认聊 3 轮, 心理医生 5 轮
  没人说话就自动休眠
```
