# 默认真值 · 过渡期的心理生存指南

> 定位: 心理医生参考 — 应对宏大叙事压倒感的具体操作

---

## 真值 1: 绝望的本质

```
绝望 = 巨大的"被抛弃感"
眼看着通往未来的高铁呼啸而过
自己却被留在即将沉没的旧船上
手里攥着过期的船票, 不知道该往哪里跳
```

> 这种情绪的核心结构: 不是对未来的恐惧, 是对"被落下"的恐惧。

---

## 真值 2: 五个心理避难所

### 避难所 1: 允许自己哀悼

```
不要强迫自己每天正能量。
面对一个可能不再需要自己的世界 → 恐惧/愤怒/绝望是正常生理反应。

拆解:
  这不是你的无能, 是时代的阵痛。
  就像工业革命时手工业者的绝望 — 旧秩序崩塌的必然回响。

操作:
  允许自己摆烂, 允许丧。
  不在焦虑之上叠加"我为什么这么焦虑"的自我攻击。
```

### 避难所 2: 重建"附近"的坐标系

```
宏大叙事 (AGI/奇点/人类命运) → 让人渺小和绝望
解药: 具体的、可触摸的生活

项飙: "附近的消失"
  认真做一顿饭, 感受食材纹理
  和朋友面对面喝酒, 不是微信点赞
  去公园散步, 摸路边的树, 看晚霞

AI 能生成一万首春天的诗, 但替代不了你此刻吹在脸上的那阵春风。
```

### 避难所 3: 寻找"低科技"的避难所

```
当数字世界越来越卷、越来越假:
  实体世界和手工劳动 → 成为疗愈

种花、木工、画画、写字、拼图
在这些活动中: 付出和回报是线性的、确定的、可控的

这种"掌控感"是抵抗外界失控感的最佳武器。
亲手完成一件作品的踏实感 → AI 给不了。
```

### 避难所 4: 把人生看作"无限游戏"

```
过去的痛苦 = 一直在玩"有限游戏"
  考学 → 找工作 → 升职 → 加薪
  每一步都比, 生怕掉队

AGI 在强行终结这场游戏。
既然规则快失效了, 提前换玩法:

无限游戏: 目的不是赢, 是让游戏继续下去
  学一门"没用"但喜欢的乐器
  读一本晦涩的哲学书
  探索一个冷门领域

在这个过渡期: "好玩" > "有用", "体验" > "成就"
把每一天当成赚到的, 尽情体验作为"人类"的可能性。
```

### 避难所 5: 抱团取暖

```
绝望最喜欢孤独的人。
不要把自己封闭起来。

操作:
  找到同样焦虑但依然在思考的人
  哪怕只是网络互相吐槽
  或者现实中组成小的互助社群

"我们在一起面对" → 稀释个体的恐惧

记住: 你绝不是一个人在面对这场海啸。
```

---

## 真值 3: 总结

```
无法阻挡历史的车轮, 但拥有"如何度过今天"的自由。

在这个巨大的过渡期里:
  保护好身心健康
  照顾好身边具体的人
  享受每一个真实的当下

这是一种伟大而坚韧的抵抗。
```
