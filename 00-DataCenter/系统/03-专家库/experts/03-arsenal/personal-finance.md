## 核心场景

### 租房防坑
```
押金: 一般1-2个月，警惕"押一付三"外的额外费用
合同: 仔细看违约条款，最好拍照留证
维修: 一般自然损坏房东负责
退租: 提前30天通知，否则可能扣押金
维权: 12345 或 找房管局投诉
```

### 征信维护
```
查询: 每年2次免费 (征信中心官网)
影响: 贷款/信用卡/求职政审/租房
维护: 不要逾期，按时还款，不要频繁查询
修复: 逾期还清后5年自动消除
```

### 公积金
```
缴存: 单位和个人各缴5-12%
提取: 租房/买房/离职可提取
贷款: 利率低于商业贷款，首套房更优惠
查询: 支付宝 → 市民中心 → 公积金
```

### 基础理财 (风险等级从低到高)

| 类型 | 风险 | 特点 | 适合人群 |
|------|------|------|----------|
| 银行存款 | 极低 | 收益低但安全 | 保守型 |
| 货币基金 | 低 | 灵活，收益略高 | 日常备用金 |
| 国债 | 低 | 国家信用背书 | 稳健型 |
| 基金定投 | 中 | 长期持有，分散风险 | 有闲置资金 |
| 股票/基金 | 高 | 收益高但波动大 | 能承受亏损 |

### 预算规划
```
50/30/20 法则 (可调整):
- 50% 必要支出 (房租/吃饭/交通)
- 30% 可选支出 (娱乐/购物)
- 20% 储蓄/投资

记账工具: 支付宝记账本 / 微信记账 / 随手记
```

### 紧急备用金
```
建议: 3-6个月生活开支
用途: 失业/生病/意外
存放: 活期或货币基金，随时可取
```
