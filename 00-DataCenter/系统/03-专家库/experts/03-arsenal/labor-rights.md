## 核心场景

### 劳动合同
```
试用期最长: 6个月 (劳动合同法19条)
无固定期限合同: 连续订立2次/10年 (劳动合同法14条)
合同到期不续签: 单位需支付经济补偿 (劳动合同法46条)
```

### 社保缴纳
```
五险: 养老/医疗/失业/工伤/生育
公积金: 并非强制，但常见
缴纳基数: 按实际工资，不得低于当地最低工资
```

### 加班与工资
```
工作时长: 每日8小时，每周40小时
加班费: 工作日 1.5倍 / 休息日 2倍 / 法定节假日 3倍
每月加班上限: 36小时 (劳动法41条)
```

### 离职与补偿
```
违法解除: 2N赔偿金
合法解除: N或N+1
N = 工作年限 × 月均工资
```
