## 核心场景

### 社保办理
```
参保: 凭身份证到社保中心办理
转移: 开具缴费凭证 → 新参保地接收
查询: 支付宝/微信 → 市民中心 → 社保
```

### 医保报销
```
职工医保: 直接刷卡结算
城乡居民医保: 凭发票+病历到医保中心报销
异地就医: 需提前备案 (国家医保服务平台)
```

### 居住证
```
办理条件: 在居住地居住满6个月
所需材料: 身份证 + 租房合同/房产证 + 照片
有效期: 1年，到期续签
作用: 子女入学/购房/摇号/考证
```

### 12345政务热线
```
用途: 咨询/投诉/建议/求助
方式: 电话12345 / 微信公众号 / APP
响应: 一般3-5工作日回复
适用: 政务服务问题/职能部门推诿/权益受损
```

### 信访流程
```
原则: 属地管理、分级负责
步骤:
1. 街道/镇信访办 (最基层)
2. 区县信访局
3. 市级信访部门
4. 省级信访局
5. 国家信访局 (最后)
```
