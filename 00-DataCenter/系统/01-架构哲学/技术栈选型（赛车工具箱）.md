# 技术栈选型（赛车工具箱）

核心语言: Python 3.11+（极致异步性能+类型提示）
数据与配置: Pydantic V2（LLM输出强约束+系统配置管理）
异步与网络: httpx + asyncio（全链路异步避免I/O阻塞）
沙箱执行: Docker SDK for Python（AI代码隔离执行，用完即销毁）
CLI交互: Typer + Rich（状态机流转实时打印+彩色日志+表格）
日志追踪: Loguru（开发期调试）+ Langfuse（自控LLM观测平台）
